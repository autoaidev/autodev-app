2AutoDev desktop — rebuilt from the real screens

What I changed and why. The current app repeats the same information on every row (each of 29 agents carries an identical office badge, provider, and id) so nothing stands out; six tabs split one agent across six places, of which Overview shows four zeros and Output shows unparsed ANSI escapes; and Pixel Office scrolls three columns simultaneously. The rebuild: one detail surface, not six tabs — live work on the left, Todo/session/config in a fixed inspector on the right, and Config moves to a modal since it is edited rarely. Rows carry only what differs — the office name lives on the group header, the id and provider collapse into one dim meta line, and the right edge is reserved for the single number that matters (tasks left). Logs are parsed, not echoed — timestamps stripped to a gutter, severity coloured, repeated MCP lines folded into one summary row. A Fleet view answers "what needs me" across 29 agents, which no current screen does. Same IDE-native dark palette, one blue accent, status colours reserved for state.
